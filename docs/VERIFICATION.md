검사 결과와 화면은 `tmp/browser-checks/workflow-result.json`, `workflow-*.png`에 있습니다. 실제 학생 사용 효과를 측정한 결과는 아닙니다. 신규 기수별 집계와 후속 집계는 브라우저 저장소 검사이며 실제 서버 연동은 미완료입니다.

검증일: 2026-11-10. 사용자의 후속 요청에 따라 Supabase 신규 프로젝트 연결은 보류하고 테스트 데이터로 UI를 검증했습니다.

## 브라우저

Python Playwright와 Edge로 로컬 Vite 화면을 확인했습니다. 아래 검사는 가상 계정과 브라우저 저장소를 이용합니다. 실제 서버 보안 검사의 대체물이 아닙니다.

- 학생 A/B 화면의 프로필과 지원서 분리
- 학생 화면에 담당 공고 관리 진입이 없음
- 프로필 수정, 규칙 판정, 직접 작성, TXT 다운로드
- 자동저장, 로그아웃 후 다시 진입, 새로고침 후 작성 내용 복원
- 준비 체크리스트와 후속 절차 상태 복원
- 저장소 예외 발생 시 오류 표시, 내용 유지, 재시도
- 활동 저장을 1.2초 지연시킨 동안 수정한 마지막 내용도 로그아웃 전 저장
- 실제 수집 공고 검색, 원문 링크, 관심 등록과 관심 목록
- 가상 시연 4건과 담당자가 테스트 게시한 공고 구분
- 담당자 A/B 목록 분리, 공고 임시저장과 수정
- 조건, 제출 항목, 작성 문항, 후속 절차, 원문 근거 편집
- 수정 시 검수 확인 초기화, 검수 후 게시, 게시 종료
- 담당자가 게시한 공고에서 학생의 준비 시작과 작성
- 담당자 편집 중 저장 실패와 입력 유지
- 미저장 공고를 둔 채 메뉴 이동 또는 종료 시 경고와 취소
- 집계 공고와 기간, 분모 표시, 소수 인원 비공개
- 담당자 집계에서 학생의 지원서 본문 미노출
- 390px 모바일과 1440px 데스크톱의 주요 학생/담당자 흐름
- 가로 넘침 없음, 자바스크립트 런타임 오류 없음

## 규칙

`npm test`: 12개 통과. 규칙 6개, 테스트 공고/집계 6개.

미입력, 공백, 잘못된 숫자는 확인 필요입니다. 0은 실제 값입니다. 직접 확인 조건은 프로필 값을 조작해도 확인 필요입니다. 자격 조건과 서류 준비율은 분리합니다. 링크는 완료로 계산하지 않습니다.

## PostgreSQL 권한

`npm run test:db`: PGlite PostgreSQL에서 22개 검증 그룹 통과. 실제 SQL 정책과 RPC를 실행하며 `auth.uid()`의 인증 사용자 식별만 테스트 함수로 대체합니다.

- 학생 A는 B의 조회, 수정, 삭제, 덮어쓰기를 할 수 없음
- 학생은 담당자 권한을 부여하거나 공고를 등록할 수 없음
- 담당자 A는 B의 공고 수정, 소유권 변경, 집계 호출을 할 수 없음
- 검수하지 않은 게시와 잘못된 형식 31개를 DB가 거절
- 게시 공고를 학생이 읽고 준비 기록을 저장
- 담당자는 다른 학생의 정보와 지원서, 원시 행동 기록을 읽을 수 없음
- DB 사용자 전환 후에도 본인 작성 내용 복원
- 소수 인원과 분모에 공개 제한 적용
- 반복 활동의 고유 사용자 집계, 신청 링크와 제출 자기보고 분리
- 한국 시간의 집계 기간, 담당자 권한 회수의 즉시 반영

## 아직 검증하지 않은 것

실제 Supabase 이메일 가입, 로그인, 토큰 갱신, 클라우드 마이그레이션 적용, 기기 간 동기화는 연결 후 별도 검증해야 합니다. 현재 배포본에서 실제 학생 개인정보를 받아 운영할 수 있다는 뜻이 아닙니다. 브라우저 테스트 모드는 같은 브라우저 저장소를 공유하므로 개발자 도구로 다른 테스트 계정 데이터에 접근할 수 있습니다.

카카오 발송, AI 추출, 학교 학적과 공식 접수 연동은 구현하지 않았습니다. 학생 개인정보와 지원서 본문을 AI로 보내는 코드는 없습니다.

## 수치 확인 → 수정 → 복귀 검증

`check_dashboard_flow.py`를 추가했습니다. Edge 1440px/390px에서 최근7일 선택, KPI로 비교표 이동, 선택 공고의 5개 수치 일치, 올바른 공고 수정, 미저장 이동 취소, 게시 후 같은 출처/기간/정렬/공고/위치로 복귀를 검증했습니다. 개별 집계에서 수정한 뒤에도 적용 기간이 유지됩니다. 저장 성공 시 화면을 맨 위로 이동시키지 않습니다.

일반 모드에서 그래프와 펼침 애니메이션이 적용됩니다. 동작 줄이기 설정에서는 그래프/패널 animationName=none, 버튼 transitionDuration=0s를 확인했습니다. 런타임/콘솔 오류와 가로 넘침이 없었습니다.

담당자 저장 요청을 지연한 별도 검증에서 테스트 종료, 로그아웃, 내부 메뉴와 복귀 버튼은 비활성화됩니다. 외부 학생 메뉴를 눌러도 편집 화면을 유지합니다. 저장 응답 후 정상적으로 다시 이동할 수 있습니다.

학생 기본 흐름, 저장 중 입력 경합, 개선한 학생 UX, 담당자 기존 기능도 다시 통과했습니다. Supabase 연결은 추가하지 않았습니다.
