# 담당자 대시보드 참고 SaaS

확인일: 2026-11-10. 아래 공식 제품 문서에서 공고와 신청 관리에 필요한 정보 배치를 참고했습니다. 색과 간격은 기존 CUK ACTION 디자인을 유지합니다.

| 도구 | 확인한 요소 | CUK ACTION 적용 |
|---|---|---|
| [Submittable Program Insights](https://submittable.help/en/articles/10139823-program-insights) | 프로그램별 핵심 지표와 상태별 시각화 | 상단 조회, 관심, 준비, 자기보고 지표와 단계별 비교 |
| [Airtable Interface Designer](https://www.airtable.com/guides/collaborate/interface-designer-dashboards) | 큰 숫자를 모아 배치하고 추이 차트, 일정, 표를 조합 | KPI 묶음, 날짜별 그래프, 가까운 마감, 공고 비교표 |
| [SurveyMonkey Apply All Programs Reports](https://help.surveymonkey.com/en/apply/analyze/program-reports/) | 여러 프로그램을 하나의 보고서에서 비교하고 필터 적용 | 담당 공고 통합 집계, 기간 필터와 공고별 비교 |

## 구현 판단

첫 화면의 순서는 공고 상태, 집계 범위, 핵심 지표, 날짜별 추이, 해야 할 일, 단계별 비교, 공고별 표입니다. 수치를 확인한 뒤 바로 공고를 수정하거나 검수 목록으로 이동할 수 있습니다.

그래프에는 날짜와 인원 축, 범례, 날짜별 수치, 키보드로 움직일 수 있는 날짜 선택, 데이터 표를 제공합니다. 모바일 비교표는 내부에서 좌우로 스크롤합니다.

Submittable의 개인별 작성 필드 분석이나 자격별 분해는 가져오지 않았습니다. CUK ACTION 담당자에게 학생 본문과 민감정보를 노출하지 않는 원칙을 유지합니다. 공식 접수도 연동되지 않았으므로 제출 자기보고와 링크 이동만 구분해 표시합니다.

가상 시나리오와 이 브라우저의 행동 기록은 별도로 선택합니다. 상단 인원은 선택 기간의 고유 사용자입니다. 공고별 인원이나 일별 인원을 더한 값과 다를 수 있습니다. 1~4명은 비공개이며 빈 수치를 0으로 대신 표시하지 않습니다.
