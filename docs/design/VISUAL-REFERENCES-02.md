# 시각 레퍼런스 재조사

확인일: 2026-11-11. 사용자 피드백: Before가 After보다 더 아름답다. 기존 After의 시각적 방향은 채택 보류.

## 이전 조사에서 부족했던 부분

GitHub와 공식 문서를 확인한 것은 사실이다. 하지만 컴포넌트 접근성과 라이선스 조사가 화면의 시각적 완성도를 보장하지는 않는다. Submittable은 작은 메뉴 캡처, Airtable은 그리드 일부, Apply는 공개 신청 포털을 보았다. 제품의 전체 홈과 상세를 비교할 시각 근거가 부족했다.

기존 After는 카드와 일러스트를 없애고 행 목록으로 정리하는 데 치우쳤다. 글자를 일괄 키우면서 제목, 보조 정보, 컨트롤의 크기 차이가 줄었다. 넓어진 입력과 반복된 안내가 화면을 길게 만들었다. 기존 CUK의 남색 히어로, 아이콘, 카드 간 균형을 충분히 살리지 못했다.

접근성 대비 개선과 업무 의미 보존은 계속 유효하다. 화면 구성과 밀도, 글자 단계는 다시 검토한다. 기존 After를 작업 3의 확정 디자인으로 적용하지 않는다.

## 이번 자료의 확인 수준

공식 제품 소개/도움말에 실린 실제 제품 화면을 브라우저에서 렌더링하고 이미지 영역을 캡처했다. 로그인 후 직접 사용한 화면은 아니다. 소개 페이지에서 배경이나 프레임을 합성한 이미지는 보드에 따로 표시한다. 현재 모든 계정에서 동일한 UI라고 단정하지 않는다.

| 제품 | 실제로 확보한 화면 | 비교할 요소 | CUK 적용 후보 |
|---|---|---|---|
| Asana | Home, My tasks와 프로젝트 위젯, 작업 카드 일부 | 홈의 큰 제목, 두 개의 주 영역, 패널 안의 작은 행, 절제된 테두리 | 학생 홈의 주 레퍼런스. 기존 남색 히어로와 카드형 공고를 살려 정돈 |
| Linear | Project overview와 속성/리소스, 프로젝트 팀 선택 | 문서 중심 본문, 압축된 속성, 제목/설명/리소스의 위계 | 신청 준비 상세의 보조 기준. 어두운 테마나 작은 글자를 그대로 가져오지 않음 |
| Notion | My Tasks, 필터 펼침, 새 작업 입력 | 고정된 작은 사이드바, 간결한 도구 모음, 행의 수평 정렬 | 담당자 비교와 내 신청 목록의 보조 기준. 학생 홈 전체를 무채색 표로 변경하지 않음 |

| Basecamp | Card Table과 카드 작성 | 연한 카드 표면, 단계별 구분, 짧은 속성 입력과 넓은 본문 | 카드 형태와 작성 집중도 참고. 칸반 기능 추가는 제외 |

추천 방향은 Asana의 홈 구성에 가깝다. 이는 제품을 섞어 복제한다는 뜻이 아니다. CUK의 브랜드와 기존 카드 스타일을 유지하고, 어디에 무엇을 얼마나 놓을지 비교한다. Linear와 Notion은 상세/목록의 구체적인 부분을 비교하는 자료다.

## 화면별 살릴 것과 고칠 것

| 화면 | 기존 Before에서 유지 | 다시 설계할 부분 |
|---|---|---|
| 학생 홈 | 남색 히어로, 작은 삽화, 오른쪽 신청 현황, 공고 카드 2열 | 테스트 안내 높이, 중복 필터, 본문 대비, 긴 카드 전 설명 |
| 준비 상세 | 조건/작성/준비 탭, 둥근 패널, 옆 안내 영역 | 마감과 선택 기수의 위치, 저장 상태, 중요한 경고와 접을 근거 구분 |
| 담당자 | 브랜드 내비게이션, 지표 색, 상태 배지 | 큰 반복 카드의 높이, 공고별 비교와 수정 진입, 선택 행 상세 |

## 출처

- [Asana Home](https://asana.com/features/project-management/home): 공식 제품 소개. 홈 화면과 위젯을 보여주는 연출 이미지 포함.
- [Linear Projects](https://linear.app/docs/projects): 공식 도움말. 프로젝트 상세 화면.
- [Linear My issues](https://linear.app/docs/my-issues): 공식 도움말. 추가 확보 여부는 보드와 sources.json 기준.
- [Notion My Tasks](https://www.notion.com/en-gb/help/guides/give-your-to-dos-a-home-with-task-databases): 공식 가이드. 목록, 필터와 새 작업 화면.
- [Basecamp Card Tables](https://5.basecamp-help.com/article/1063-card-tables): 공식 도움말. 추가 확보 여부는 보드와 sources.json 기준.

Attio와 ClickUp도 조사했으나 최초 캡처에서 사용할 제품 이미지가 확보되지 않았다. Attio 추가 요청은 로딩 타임아웃이었다. 해당 자료를 확보한 시각 레퍼런스로 세지 않는다.

증거 폴더: `_ref/uiux-2026-11-11/visual-references/`. `sources.json`은 출처 페이지, 원본 이미지 URL, 캡처 파일을 연결한다. 코드를 복제하거나 제품 자산으로 사용하지 않는다. 내부 비교용 화면 자료다.

이번 단계는 레퍼런스 비교다. 새 CUK 화면을 임의로 확정하지 않는다. 방향을 정한 뒤 해당 화면의 간격을 추정 또는 실측해 기존 토큰과 비교한다. 홍보 페이지의 바깥 여백을 제품 내부 간격으로 측정하지 않는다.
