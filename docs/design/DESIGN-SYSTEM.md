## 타이포그래피

외부 폰트 요청 없음. `'맑은 고딕', 'Apple SD Gothic Neo', sans-serif`. 배포 환경별 글꼴 차이를 허용하고 줄바꿈으로 수용한다. 임의 영문 디스플레이 폰트를 추가하지 않는다.

| 역할 | 데스크톱 | 모바일 | 줄높이 / 굵기 |
|---|---|---|---|
| 화면 제목 h1 | 28px | 24px | 1.4 / 700 |
| 섹션 제목 h2 | 20px | 20px | 1.5 / 700 |
| 항목 제목 h3 | 16px | 16px | 1.5 / 600~700 |
| 본문, 입력 | 16px | 16px | 1.6 / 400 |
| 보조, 필터, 배지, 버튼 | 14px | 14px | 1.6 / 400~600 |
| 집계 숫자 | 28px | 24px | 1.3 / 700 |

9~11px의 현재 상태 문구는 14px로 상향. 학년, 날짜, 건수처럼 비교하는 값에 `font-variant-numeric:tabular-nums`. 인원은 `1,234명`. `null`과 `undefined`를 `0`으로 대체하지 않는다. 0은 `0명`, 억제 값은 `비공개`, 연결 안 된 공식 접수는 `미연동`.

날짜: 상세에서 `2026.11.18 18:00 / 한국 시간`. 목록에서는 같은 해에 한해 `11.18`, 상세에서 연도 제공. 시각 미확인은 `시각 확인 필요`. 날짜도 없으면 `일정 확인 필요`. 충돌이면 `자료 불일치`. D-day만 단독 제공하지 않는다. 공고 목록의 연도/시각 축약으로 마감 규칙을 바꾸지 않는다.

## 간격과 화면

기존 추정 간격 카드 계승. 0을 제외한 padding, margin, gap은 아래 토큰만 사용한다. 행 높이, 아이콘 크기, 테두리, 모서리, 초점 offset은 간격 단계와 다른 치수다.

| 토큰 | 값 | 역할 |
|---|---:|---|
| `--sp-1` | 8px | 아이콘과 라벨, 짧은 문구 사이 |
| `--sp-2` | 16px | 입력 묶음, 행 셀 안쪽, 모바일 좌우 |
| `--sp-3` | 24px | 패널 안쪽, 열 사이, 모바일 화면 상하 |
| `--sp-4` | 32px | 섹션 사이, 데스크톱 화면 안쪽 |
| `--sp-5` | 48px | 큰 영역 분리, 빈 화면 안쪽 |
| `--sp-6` | 64px | 독립 빈 화면의 큰 여백 |

레이아웃: 데스크톱 Sidebar 224px, topbar 최소 64px, 본문 최대 1200px. 1440px 화면에서 작업 면적을 확보한다. 현재 246px Sidebar와 48px main padding은 각각 224px, 32px로 제안한다. 상세는 `minmax(0,1fr) 280px`, 간격 24px. 장문 입력 최대 폭은 760px를 권장하되 별도 패널에 강제로 가두지 않는다.

반응형:

- 1024px 이상: 고정 Sidebar, 상세 2열.
- 680~1023px: Sidebar를 기존 메뉴 열기 방식으로 전환. 상세 1열. 표는 내부 스크롤.
- 679px 이하: 화면 좌우 16px, 패널 안쪽 16px. 목록은 제목 행과 상태/행동 행으로 구성. 입력 16px 유지. 작업 본문 뒤에 보조 요약 배치.
- 최소 검사: 320, 390, 1440px. 200% 확대에서 컨트롤 겹침 없음. 비교표만 내부 가로 스크롤 허용. `role=region`, 이름, `tabindex=0`, 가로 이동 안내 제공.

모바일 내비게이션은 제품의 기존 메뉴 동작을 유지한다. 미리보기의 3개 화면 전환 버튼은 설계 검토 도구이며 제품 메뉴가 아니다. 학생에게 담당자 메뉴를 추가하지 않는다.

## 모양과 동작

패널 모서리 16px 유지. 입력/버튼 8px, 작은 배지 4px. 일반 패널에 그림자 없음. Dialog/Toast에만 기존 `0 12px 40px #14254b0d`. 아이콘은 기존 lucide-react 16/20/24px, 장식은 `aria-hidden`, 아이콘 전용 버튼은 이름 필수. 로고는 기존 자산 유지. 시안의 C 글자는 임시 표시다.

동작은 120~160ms의 배경/투명도 변화에 제한. 숫자 증가 애니메이션 없음. 버튼 hover에서 위로 이동하는 효과 제거 제안. `prefers-reduced-motion: reduce`에서 애니메이션과 smooth scroll 제거. 성공 알림을 잠깐 보여주는 Toast만으로 저장 상태를 전달하지 않는다.

## 의미 보존 규칙

`조건 충족`은 제공된 정보와 검수 조건 비교 결과다. `준비 완료`는 체크리스트 완료다. `신청 경로 이동`은 링크 클릭 기록이다. `제출 자기보고`는 학생의 표시다. `공식 접수`는 미연동이다. 이 다섯 값은 서로 자동 승격하지 않는다.

1~4명은 비공개. 관리자에게 작성본문, 개인별 조건, 학생 명단을 새로 제공하지 않는다. `가상 시나리오`, `이 브라우저 기록`, `서비스 기록` 출처를 같은 집계처럼 섞지 않는다. 보관 공고는 수집 시점과 미검수 여부를 유지한다.
